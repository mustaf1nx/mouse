# Mouse Assistant — полный гайд

Версия исходников: v19-choice-control-index. Сборка для Windows x64. Это локальный тренировочный помощник; результат AI нужно проверять самостоятельно.

## 1. Что находится в комплекте

- `windows/MouseAssistant.exe` — клиент без окна, снимающий вопрос и управляющий указанием курсора.
- `windows/MouseAssistantServer.exe` — сервер, который обращается к Claude. Он запускается с консолью для диагностики.
- `windows/client.env.example` и `windows/server.env.example` — шаблоны настроек без ключей.
- `src/` — исходный код клиента и сервера.
- `build.ps1` — повторная сборка на Windows с установленным Python.

Клиентский EXE не содержит сервер и не заменяет его. При работе с удалённым сервером запускается только клиент. При локальной работе нужны оба процесса. Python для готовых EXE не нужен. Подключение к интернету требуется серверу для запросов к Claude.

## 2. Первый запуск на этом компьютере

1. Распакуй архив в отдельную папку, например `Documents/MouseAssistant`. Не запускай прямо из ZIP.
2. Заверши старый Python-клиент: удерживай колёсико мыши не менее 2 секунд. Разные папки установки могут запускать отдельные экземпляры; используй один клиент.
3. Скопируй свой существующий `client.env` из папки `Desktop/mouse-assistant` рядом с `MouseAssistant.exe`. Не публикуй этот файл.
4. Если уже работает старый сервер на `127.0.0.1:8000`, его можно оставить: новый клиент использует тот же адрес. Второй сервер на том же порту не запускай.
5. Если хочешь заменить сервер на EXE, сначала останови старый сервер. Скопируй существующий `.env` рядом с `MouseAssistantServer.exe`, затем запусти серверный EXE.
6. Открой `http://127.0.0.1:8000/health`: должно быть `status: ok`, а для запросов к Claude — `api_configured: true`.
7. Запусти `MouseAssistant.exe` двойным щелчком. Отсутствие окна нормально. Запуск можно проверить в журнале клиента.

Для остановки сервера закрой его консоль или нажми в ней Ctrl+C. Клиент останавливается удержанием средней кнопки 2 секунды. Остановка клиента не останавливает сервер.

## 3. Настройка с нуля

Скопируй `client.env.example` в `client.env`, а `server.env.example` в `.env` рядом с соответствующими EXE. Проверь, что Windows не добавила расширение `.txt`.

Клиент:

```dotenv
SERVER_URL=http://127.0.0.1:8000
AUTH_TOKEN=ОДИН_И_ТОТ_ЖЕ_СЛУЧАЙНЫЙ_ТОКЕН
```

Сервер:

```dotenv
ANTHROPIC_API_KEY=ТВОЙ_КЛЮЧ
AUTH_TOKEN=ОДИН_И_ТОТ_ЖЕ_СЛУЧАЙНЫЙ_ТОКЕН
SERVER_HOST=127.0.0.1
CLAUDE_MODEL=ДОСТУПНЫЙ_ТЕБЕ_ID_МОДЕЛИ
SAVE_SCREENSHOTS=false
```

Не ставь обратные слеши перед двоеточием или в конце строк. После изменения настроек перезапусти соответствующий процесс. Ключ Claude нужен только серверу; токен клиента и сервера должен совпадать.

Для удалённого сервера укажи его адрес в `SERVER_URL`. Развёртывание backend и отправка кода в Git — разные операции. Не открывай локальный сервер всему интернету без настройки доступа и защищённого соединения. Этот комплект по умолчанию слушает только `127.0.0.1`.

## 4. Общие правила

- Покажи вопрос целиком вместе с вариантами. Голубой блок не должен быть обрезан краем окна.
- Наведи курсор внутрь нужного голубого блока. При нескольких вопросах выбирается блок под курсором.
- Запуск: **одно нажатие колёсика**, **Mouse 5** или **правый Alt**. В Windows эти триггеры перехватываются, чтобы не запускать автопрокрутку или переход вперёд.
- Пока идёт запрос, не двигай мышь, не прокручивай и не меняй вопрос. Ответ старше 30 секунд отбрасывается.
- Повторное нажатие во время запроса игнорируется, а не создаёт второй запрос.
- Курсор обычно перемещается только вертикально; по горизонтали его размещаешь ты. Программа не нажимает варианты и не отправляет тест.
- Ручное движение во время указания прерывает движение. Плавный разгон и торможение уже есть; имитация непредсказуемой траектории в эту версию не добавлена.
- Если ничего не произошло, это не означает, что вариант под курсором правильный: возможно, запрос отменён или ответ не прошёл проверку.

## 5. Один правильный ответ

1. Поставь курсор внутри вопроса и запусти анализ.
2. Дождись перемещения на высоту правильного варианта. В v19 клиент получает номер ответа и общее число вариантов, затем находит реальные кружки выбора на снимке. Если число кружков не совпало или распознавание неоднозначно, движение отменяется. Это исправление относится к одиночному выбору; очередь нескольких галочек использует координаты AI.
3. Сам выбери вариант левой кнопкой.

Если курсор уже на нужной высоте, он немного сдвигается вверх и возвращается. Это подтверждение полученного ответа, а не гарантия его правильности.

## 6. Текст и числа

1. Поле ответа должно быть пустым. Запусти анализ и дождись короткого дрожания курсора.
2. После окончания дрожания есть 30 секунд, чтобы щёлкнуть левой кнопкой внутри пустого поля.
3. Программа проверяет поле и печатает текст. Enter не нажимается; отправляешь ответ сам.
4. Ответ одновременно копируется в буфер. Если печать не состоялась, можно вставить его вручную через Ctrl+V.

Если поле уже заполнено, автоматической замены не будет. Если текст напечатан частично, проверь его перед вставкой, чтобы не создать дубликат. Ручной ввод, клик вне распознанного поля, изменение вопроса или истечение времени отменяют ожидающую печать.

Дрожание означает готовность режима ввода. Оно не означает, что текст уже введён. Автоматический ввод проверяет доступность поля через Windows UI Automation; некоторые приложения не предоставляют нужных сведений, и тогда остаётся ручная вставка.

## 7. Несколько правильных вариантов — галочки

1. Запусти анализ: программа получает весь набор и указывает первый вариант сверху вниз.
2. Сам поставь галочку.
3. Снова нажми триггер: он укажет следующий вариант без нового запроса к Claude.
4. Повторяй. После последнего варианта очередное нажатие даёт короткое дрожание: очередь закончилась.

Очередь хранится до 120 секунд. Прокрутка сбрасывает её. Изменение текста вопроса, размеров окна или уход курсора из блока также требует нового анализа. Не снимай уже выбранные правильные галочки при повторной проверке. Программа считает показанные варианты, а не проверяет итоговое состояние всех галочек.

## 8. Выпадающий список и сопоставление

Первый этап — закрытые списки:

1. Закрой меню, оставь весь вопрос видимым, наведи курсор на голубой блок и нажми триггер.
2. Дождись дрожания: строки подготовлены. На этом этапе конкретный пункт ещё не указан.

Второй этап — открытое меню:

3. Открой первый список сверху.
4. Наведи курсор внутрь раскрытого меню, чтобы его горизонтальная позиция попадала в пункты.
5. Нажми триггер и не двигай мышь до ответа.
6. Курсор укажет высоту нужного видимого пункта. Сам нажми на этот пункт.
7. Для сопоставления открой следующий список и повтори шаги 4–6. После последней строки следующий триггер даёт дрожание.

На втором этапе снимается окно целиком, потому что меню может выходить за голубой блок. В запрос может попасть остальное видимое содержимое окна. Программа проверяет открытый список отдельно и не должна выбирать пункт, который не виден.

Очередь живёт до 180 секунд с подготовки. Прокрутка меню сохраняет контекст, но отменяет текущее указание: после прокрутки нужен новый триггер. Прокрутка самой страницы может изменить расположение вопроса; тогда закрой меню и подготовь вопрос заново.

Строка переключается после твоего клика в область указанного пункта. Программа не читает фактическое сохранённое значение сайта: проверь его визуально. Если выбрал другой пункт, закрыл меню или переместил страницу, повтори подготовку с первой строки. После перезапуска очередь всегда начинается с первой строки; уже заполненные поля очищать не требуется.

## 9. Проверка на локальном сайте

Тестовый сайт запускается отдельно; текущий адрес — `http://127.0.0.1:8766`.

- №1: один вариант.
- №2: число, №3: текст.
- №4: несколько галочек.
- №5: один выпадающий список.
- №6: сопоставление из пяти списков.

В Practice settings можно включить запрет вставки для проверки именно печати и анимированную имитацию камеры для проверки сравнения пикселей. Таймер и имитация камеры должны оставаться вне голубого блока. Режим Show all questions позволяет проверить выбор блока курсором.

## 10. Логи и ошибки

Для одиночного выбора последний снимок с красной отметкой цели сохраняется локально как `last-choice-target.png`, а координаты — как `last-choice-target.json` в папке журнала клиента. Эти файлы перезаписываются и не включаются в Git.

Клиент: `%LOCALAPPDATA%\MouseAssistant\client.log`.

Сервер: `data\logs\server.log` рядом с серверным EXE, если `DATA_DIR` не переопределён.

Для просмотра клиента в PowerShell:

```powershell
Get-Content "$env:LOCALAPPDATA\MouseAssistant\client.log" -Tail 40 -Wait
```

| Запись | Значение и действие |
|---|---|
| `VERSION` / `Started` | Клиент запущен. Проверь дату и время, чтобы не читать старую сессию. |
| `SEND` | Снимок отправлен серверу. |
| `HTTP 200` | Сервер ответил, но внутри ответа всё ещё может быть отказ анализа. |
| `low_confidence` | Ответ не прошёл порог: конечный пункт/текст — 0.85, подготовка списков — 0.80. Эти числа не являются измеренной вероятностью правильности. |
| `No blue question block` | Покажи голубой блок целиком. Если открыто меню, закрой его и начни подготовку заново. |
| `question changed` / `pixels changed` | Сравнение обнаружило изменение. Не прокручивай и не перекрывай вопрос, повтори анализ. |
| `cursor moved while waiting` | Мышь двигалась до получения ответа. Повтори и дождись окончания. |
| `TEXT READY` | Можно кликнуть в пустое поле в течение 30 секунд. |
| `cannot verify editable field` | Поле не доступно через UI Automation; используй вставку. |
| `field is not empty` | Заполненное поле не заменяется автоматически. |
| `DROPDOWN REJECTED` | Дальше указан код и причина: формат JSON, уверенность, координаты либо неопределённый ответ. |
| `DROPDOWN RESET` | Контекст потерял актуальность. Закрой меню и подготовь вопрос заново. |
| `BUSY` | Предыдущий запрос ещё выполняется. |
| `ALREADY RUNNING` | Из этой папки уже запущен клиент. |
| HTTP 401 | Токены клиента и сервера не совпадают. |
| HTTP 503 | На сервере не настроен ключ Claude. |

Буфер обмена после неудачного запроса может содержать предыдущий ответ. Не вставляй его без проверки готовности текущего ответа.

## 11. Ограничения и статус проверки

Windows EXE предназначены для Windows x64. На macOS EXE не запускаются. В исходниках есть часть поддержки macOS (снимки, указание, буфер), но автоматическая печать с проверкой поля реализована только для Windows; macOS-сборка не подготовлена и не проверена.

Поддерживается основной монитор; проверки нескольких мониторов не проводились. Нативные меню, масштабирование, анимации и особенности сайтов могут мешать распознаванию. Если меню закрывает вопрос, AI может отказаться указывать ответ. Прохождение модульных тестов не гарантирует распознавание всех реальных меню.

Секреты, пользовательские логи и скриншоты в комплект не включены. Наличие EXE не означает, что backend развёрнут на удалённом сервере или что изменения уже отправлены в Git.
